# min-null

Организация `min-null`. Этот репозиторий — общий контур: процесс разработки и
релиза, правила для агентов и общие GitHub defaults.

## Процесс

- [Единый флоу разработки и релиза](docs/development-flow.md) — канон для всех
  репозиториев: задача, product gate, ветки, PR, `develop → main`, release tag,
  deploy, rollback.

Начните с него. Репозитории организации не описывают процесс заново — они
хранят код, контракты, окружения и собственные runbook'и.

## Правила для агентов
